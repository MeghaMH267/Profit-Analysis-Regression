# Profit Analysis & Regression

## Project Overview

This project analyzes the profitability of 50 startups using business expenditure data. The analysis focuses on understanding how **R&D Spend, Marketing Spend, and Administration Spend** influence company profit.

The project combines data analysis, correlation analysis, regression analysis, and Power BI visualization to generate business insights and support profit prediction.

## Objective

The main objectives of this project are:

- Analyze startup expenditure and profitability
- Identify factors that influence profit
- Compare profitability across different states
- Study the relationship between expenditure and profit
- Perform correlation and regression analysis
- Predict profit using a regression model
- Present insights through an interactive Power BI dashboard

## Dataset

The project uses the **50 Startups dataset**, containing 50 records with the following variables:

| Column | Description |
|---|---|
| R&D Spend | Amount spent on research and development |
| Marketing Spend | Amount spent on marketing activities |
| Administration | Administrative expenditure |
| State | State in which the startup operates |
| Profit | Profit generated by the startup |
