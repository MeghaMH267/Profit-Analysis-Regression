# Profit Analysis & Regression

## Project Overview

This project analyzes the relationship between business expenditure and profit using the **50 Startups dataset**.

The analysis focuses on R&D Spend, Marketing Spend, Administration Spend, State, and Profit to identify the factors that have the strongest relationship with company profitability.

## Objective

The main objectives of this project are to:

- Analyze company expenditure and profitability
- Compare profit across different states
- Identify relationships between spending and profit
- Analyze the correlation between R&D, Marketing, Administration, and Profit
- Build a regression-based profit prediction model
- Create an interactive Power BI dashboard

## Dataset

The dataset contains information on:

- R&D Spend
- Administration Spend
- Marketing Spend
- State
- Profit

The project uses **50 startup records** for analysis.
