# Profit Analysis & Regression

## Project Overview

This project analyzes the profitability of 50 startups using R&D Spend, Marketing Spend, Administration Spend, State, and Profit.

The project uses data analysis, correlation analysis, regression analysis, and Power BI visualization to identify factors affecting profitability.

## Objective

- Analyze startup expenditure and profitability
- Identify factors influencing profit
- Compare profitability across states
- Analyze relationships between expenditure and profit
- Perform regression analysis
- Predict profit
- Build an interactive Power BI dashboard

## Dataset

The project uses the 50 Startups dataset with the following columns:

- R&D Spend
- Administration
- Marketing Spend
- State
- Profit

## Regression Analysis

Multiple linear regression was used to analyze the relationship between R&D Spend, Marketing Spend, Administration Spend, and Profit.

The model achieved an R² value of approximately 0.95, indicating a strong relationship between the selected expenditure variables and profit in this dataset.

## Dashboard

The Power BI dashboard provides an interactive view of startup profitability, expenditure, state-wise performance, and regression analysis.

## Key Insights

- R&D Spend has the strongest positive relationship with Profit.
- Marketing Spend has a positive relationship with Profit.
- Administration Spend has a comparatively weaker relationship with Profit.
- State-wise analysis shows differences in profitability.
- Regression analysis can be used to estimate expected profit based on expenditure.
